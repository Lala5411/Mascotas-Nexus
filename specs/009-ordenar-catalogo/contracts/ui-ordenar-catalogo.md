# Contrato de interfaz: selector de orden

No hay contratos HTTP nuevos. Este es el contrato del control en la pantalla del catálogo.

| Elemento | Rol y nombre accesible | Opciones |
| --- | --- | --- |
| Selector | `combobox` «Ordenar por» | «Orden original», «Nombre (A-Z)», «Edad: menor a mayor», «Edad: mayor a menor» |

Resultado: las tarjetas visibles (después de búsqueda y filtro) se muestran en el orden elegido.
